# Easy Chemistry v5

نسخة موسعة من المنصة: تسجيل طالب ببيانات الهاتف وولي الأمر والصف، لوحة Admin، رفع فيديو/PDF إلى Supabase Storage الخاص، مشغل فيديو بسرعات وجودات، امتحانات MCQ مؤقتة وتصحيح تلقائي، وأخطاء الطالب.

## مهم قبل رفع الموقع

1. افتح Supabase > SQL Editor.
2. نفّذ الملف `v5_schema.sql` كاملًا مرة واحدة.
3. في Supabase > Authentication > Providers > Email عطّل **Confirm email** إذا كنت تريد تسجيل الطالب والدخول مباشرة بدون تأكيد بريد.
4. ارفع ملفات هذه النسخة إلى GitHub Pages.

### ملاحظات
- أرقام الطالب وولي الأمر يتم التحقق منها كأرقام مصرية تبدأ بـ 010/011/012/015.
- لا يوجد OTP في هذه النسخة؛ تسجيل الطالب يتم بالبريد وكلمة المرور مع حفظ رقم الهاتف وولي الأمر.
- الفيديوهات والـPDF تحفظ في bucket خاص `course-media`، والطالب يحصل على رابط مشاهدة مؤقت بعد تسجيل الدخول.
- الجودة المتاحة للطالب هي الجودات التي رفعها الـAdmin للمحاضرة (360p/480p/720p/1080p).
- التصحيح يتم داخل قاعدة البيانات بواسطة RPC ولا يتم إرسال الإجابة الصحيحة للطالب أثناء الامتحان.
